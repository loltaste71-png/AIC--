# 2026AIC- 榜单监控数据

这是个人从复赛开始到结束，通过记录每天的复赛成绩排行榜数据整理的数据，不作为比赛成绩评分参考。

## 数据口径

- 数据来自赛事官方公开榜单接口（`POST /third/jsphb`），无需登录，整点采集
- 每帧为按分数倒序排列的队伍列表，字段：`rank`（排名）/ `name`（队名）/ `no`（编号）/ `score`（分数）
- 复赛榜单自 2026-10-05 起冻结，末帧共 553 队

## 分析结果要点（详见 `analysis/index.html`）

- 483 帧快照，累计出现 554 支队伍，末帧 553 队
- 末帧分数分布：55-60 分区间扎堆 269 队（48.6%）
- 90 队存在单帧暴涨 ≥5 分（其中 12 队 ≥20 分）；异常判定为统计层面的模式识别，不构成对任何队伍的定性结论
- 初赛 557 队 → 复赛 554 队：533 队两赛均上榜

## 可疑队伍画像分析（`analysis/cheat_analysis.html`）

基于整点快照对末帧 553 队做统计模式识别，供复核参考，不构成对任何队伍的定性结论：

- **单帧暴涨**：60 队存在单帧跳分 ≥5 分，其中 12 队 ≥20 分（异常级）
- **末帧完全同分**：仅 1 组（57.321 分三队撞分）；分数为 3 位小数，完全同分概率极低
- **综合可疑度**：单帧暴涨 / 一次性提交高分 / 晚现即高分 / 初赛↔复赛反差 / 排名跃升 / 卡获奖线 / 末帧同分簇 / 同名异号 8 项特征加权评分
- 最集中的模式：初赛占位（8~10 分）→ 复赛 57~59 分一次性上榜（20+ 队），及单帧暴涨 ≥20 分、分数精确卡获奖线（±0.02）

## 公示交叉分析：被斩杀队伍与漏网预测（`analysis/prize_verdict.html`）

官方公示拟获奖名单后，将其与本地483帧监控快照交叉，得到以下结论：

### 被官方斩杀的20队

定义：冻结榜分数落在省一/二/三档内（前388名），但公示未获奖。分两类：

- **A类·高分凭空冒头（9队，58.7~61分）**：5队初赛缺考直接冒59+（扬帆队61.067、算力先锋60.558、定风波59.399、维度解耦59.308、扬帆远航59.303）；3队初赛前10但复测翻车（FK/AC/ini）；慧眼初赛10分532名0次变更一步到位。
- **B类·卡线同分簇（11队，56.3~57.4分）**：4个同分簇共9队全灭——57.321三队（恒视科创/不知道对不队/刀枪炮）、57.396两队（火爆奶龙/对的对的）、57.285两队（幸运星/别跟我们作队）、56.363两队（知行合一/城视融合）。

### 作弊规律（特征命中率对比）

| 特征 | 被斩杀20队 | 获奖385队 | 倍数 |
|---|---:|---:|---:|
| 同分簇（2队以上分数精确相同） | 45% | 7.3% | 6.2× |
| 初赛缺考 | 25% | 3.1% | 8× |
| 初赛弱复赛强 | 35% | 19.2% | 1.8×（弱） |
| 提交≤2次变更 | 45% | 40.5% | 1×（无区分度） |

真正硬的规律：① 2~3个初赛中游弱队抱团同分卡在省二线；② 初赛缺考直接买高分。初赛弱复赛强、提交次数少不是作弊证据。

### 漏网预测（按与被斩杀队相似度排序）

1. **58.721 刷漆队 + 从容应队（省一）**：两个初赛477/517名极弱队同分拿省一，画像与被斩杀的慧眼（532名/58.731分/未获奖）几乎一样。
2. **57.380 厚积薄发 + 焦糖味银鹭花生牛奶（省二）**：两个初赛170名左右弱队同分，复刻被斩杀的57.396簇。
3. **57.004 汉津智眸 + 清风一咪（省二）**：两个弱队同分卡省二线。
4. **4个初赛缺考独分队**（雄鹰队57.538、老天保佑队57.525、矩算知行57.057、智链细米队56.487，均省二）。

> 以上为统计画像相似度，不构成作弊指控；官方公示结果为最终裁定。
